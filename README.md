# Pizza-Prodigy-Predictive-Sales-and-Inventory-Optimization-for-Domino-s-main

Unzip the File
use internet for all installation

Install Python 3.14, then verify the installation:
    Press Windows + R, type `cmd`, and press Enter.
    In Command Prompt, run:
        python --version

Open Visual Studio Code and install the required Python extensions.

Go to File → New Window → Open Folder, then select the `Pizza-Prodigy-Predictive-Sales-and-Inventory-Optimization-for-Domino-s-main` folder.

Open the terminal and run:
    py -m venv venv
    venv\Scripts\Activate
    pip install -r requirements.txt

Run the application:
    streamlit run app.py

    ## ⚠️ Important Files – Project Files

All important dataset, trained model, notebook, and application files
used by this project are included in this GitHub repository.

### Important files included in this repository

- `Final_Ingredients.csv`
- `Final_Sales.csv`
- `Pizza_ingredients - Pizza_ingredients.csv`
- `Pizza Sale - pizza_sales.csv`
- `Purchase_Order.csv`
- `Purchase_Order_Week_Start_2015-01-05...csv`

- `Dominos-Predictive_Purchase_Order_System.ipynb`
- `app.py`
- `test.py`
- `requirements.txt`
- `Project Documentation.pdf`

The dataset files are used for analyzing pizza sales, ingredients,
purchase orders, and inventory-related information.

The trained model file is required by the application for making
predictions and optimizing inventory and purchase orders.

The notebook contains the complete machine learning workflow including
data preprocessing, analysis, model training, and evaluation.

The application files are used to run the predictive sales and
inventory optimization system.

The files are **not unnecessary** and should not be deleted from the
project.

### Files not included in this repository

- `__pycache__/`
- `*.pyc`
